# Tutorials

The notebooks are generated by `scripts/build_notebooks.py`; on every push to
`main` a GitHub Action executes them and commits them, with their outputs, in
`notebooks/`.

```{toctree}
:maxdepth: 1

notebooks/fossil_sim_scanning
notebooks/fossil_sim_interferogram
notebooks/fossil_sim_spectral_maps
```

## Hit maps and report

`examples/hitmaps.py` runs 30 days and 6 months of observations and writes
FITS hit maps (total and per Mode), figures and a markdown report:

```sh
uv run python examples/hitmaps.py [config.toml] [output_dir]
```

## Spectral maps and report

`examples/spectral_maps.py` runs the first months of the mission (default
183 days) twice with the same seed, with and without noise, and writes the
FITS spectral maps (sky, variance, diagnostics), figures and a markdown report
that checks the noise maps against the variance maps:

```sh
uv run python examples/spectral_maps.py [config.toml] [output_dir] [days]
```
